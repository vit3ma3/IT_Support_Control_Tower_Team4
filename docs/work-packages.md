**Ёмкость команды.** 8 ч в неделю на участника, 16 ч на участника за итерацию, 64 ч на команду за итерацию. До вехи M3 «Минимальная рабочая версия» (15.12.26) — две итерации, 128 ч. Оценка 115 ч оставляет резерв 13 ч (10 %). Хранилище «Информационная база 1С» отдельным пакетом не является: работы по нему входят в пакеты 1, 2, 3 и 5.

**Нагрузка по владельцам (практика 5, до детального плана):** R2 — 42 ч (пакеты 1, 5, 6.1, 6.4) при ёмкости 32 ч; R3 — 34 ч; R4 — 34 ч; R1 — 5 ч плюс координация. Перегрузка R2 — риск РК-8; часть компонентов пакетов 1 и 3 выполняют другие участники как R, распределение — в [work-plan.md](work-plan.md).
