## 3. Архитектурные решения (ADR)

| ADR | Решение | Статус | Требования |
|---|---|---|---|
| [ADR-0001](adr/ADR-0001-platform-1c-only.md) | Вся система внутри 1С:Предприятие 8.3; отдельное аналитическое приложение — только после согласования | Принято (базовый вариант) | M-01, M-10 |
| [ADR-0002](adr/ADR-0002-calculation-separate-from-report.md) | Расчёт метрик отделён от отчёта: регистры + регламентное задание и команда пересчёта | Принято | M-05 – M-08, M-13, НФТ-01 |
| [ADR-0003](adr/ADR-0003-idempotent-import-key.md) | Ключи идемпотентного импорта: `ticket_id`; для событий `ticket_id + event_type + ts` | Принято | M-13, M-04 |

Новые решения оформляются по [шаблону ADR](templates/adr.md) и проходят ревью по регламенту ([01-charter.md](01-charter.md), приложение Г).

## 4. Трассируемость R → A

| Требование | Архитектурное решение | Контейнер / компонент |
|---|---|---|
| M-01 Платформа 1С | ADR-0001 | Все контейнеры |
| M-03, M-04 Импорт и проверки | Отдельный модуль импорта с компонентами-валидаторами | Контейнер 1, К1 – К8 |
| M-05 – M-07 Расчёт SLA и загрузки | ADR-0002: расчёт в регистры | Контейнер 3 |
| M-06 Настраиваемые нормативы | Регистр нормативов, проверка P1 – P3 | Контейнер 2 |
| M-08 – M-11 Отчёт, фильтры, визуализация, экспорт | ADR-0001: СКД внутри 1С; экспорт из того же запроса | Контейнер 4 |
| M-12 Документация, аудит расчёта | Журнал загрузок и расчётов с порогами | Контейнер 5 |
| M-13 Повторяемость | ADR-0003: ключи идемпотентности; ADR-0002: пересчёт детерминирован | К7, контейнер 3 |
| M-14 Роли | Роли конфигурации 1С | Пакет 6.1 |
| НФТ-01 Производительность | ADR-0002: отчёт читает готовые результаты | Контейнеры 3, 4 |
