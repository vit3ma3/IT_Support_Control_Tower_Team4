## 1. Условия

- Проверки выполняются в учебной ИБ 1С с заполненными справочниками (`L1`, `L2`; `E01` – `E03`) и нормативами P1 15/60, P2 30/240, P3 120/480.
- Данные: контрольный набор [data/sample](../data/sample/), негативные образцы [data/sample/negative](../data/sample/negative/), полный набор ≥ 300 обращений (задача З-16).
- Ожидаемые значения пересчитаны скриптом [check_sample.py](../data/sample/check_sample.py).
- Прогонов ещё не было: все проверки в статусе «Запланировано». Подготовка — задача З-17, прогон — З-31.
