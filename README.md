# IT Support Control Tower — команда 4

Учебный проект по кейсу № 19 «Дашборд производительности ИТ-подразделения» на платформе **1С:Предприятие 8.3**.

Система предназначена для анализа соблюдения SLA и распределения нагрузки внутренней ИТ-поддержки. Руководитель сможет находить проблемные очереди и исполнителей, сравнивать показатели и выгружать результаты на основе синтетических данных об обращениях.

Импорт, хранение, проверки, расчёты, отчёт и визуализация реализуются внутри 1С ([ADR-0001](docs/adr/ADR-0001-platform-1c-only.md)). Источник — локальные синтетические CSV-файлы. Система поддерживает управленческий анализ: решения о распределении работы принимает человек.

**Статус: проектирование завершено (практики 1–6).** Конфигурация 1С и MVP разрабатываются по [плану работ](docs/work-plan.md): веха M3 «Минимальная рабочая версия» — 15.12.26, защита MVP — 22.12.26. До появления конфигурации запуск системы из репозитория недоступен.
