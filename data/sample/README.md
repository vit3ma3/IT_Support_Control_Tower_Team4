## 1. Общие правила файлов

| Параметр | Значение |
|---|---|
| Кодировка | UTF-8 без BOM |
| Разделитель | Запятая `,` |
| Первая строка | Заголовок с именами колонок; порядок колонок может быть любым, чтение по имени |
| Дата и время | `YYYY-MM-DD HH:MM:SS`, например `2026-11-02 09:00:00` |
| Часовой пояс | Все метки по московскому времени (UTC+3), зона в файле не указывается (решение команды ОВ-2) |
| Пустое значение | Пустая строка между разделителями |
| Время SLA | Календарное время, минуты: ночи и выходные считаются (решение команды ОВ-1) |

## 2. Файлы и колонки

### 2.1. `tickets.csv` — обращения

| Колонка | Тип | Обязательна | Описание |
|---|---|---|---|
| `ticket_id` | Строка до 20 символов | Да | Уникальный идентификатор обращения, ключ идемпотентности |
| `created_at` | Дата-время | Да | Время создания |
| `priority` | Строка: `P1`, `P2`, `P3` | Да | Приоритет; для него должен быть норматив (V6) |
| `queue` | Строка, код очереди | Да | Ссылка на справочник «Очереди» (V3) |
| `assignee` | Строка, код исполнителя | Да | Ссылка на справочник «Исполнители» (V3) |
| `closed_at` | Дата-время | Нет | Время закрытия; пусто — обращение открыто |

### 2.2. `events.csv` — события обращений

| Колонка | Тип | Обязательна | Описание |
|---|---|---|---|
| `ticket_id` | Строка | Да | Ссылка на обращение из `tickets.csv` или ИБ (V3) |
| `event_type` | `assigned`, `first_response`, `resolved` | Да | Тип события |
| `ts` | Дата-время | Да | Время события |

Ключ события — `ticket_id + event_type + ts` (ADR-0003).

### 2.3. `sla_targets.csv` — нормативы SLA

| Колонка | Тип | Обязательна | Описание |
|---|---|---|---|
| `priority` | `P1`, `P2`, `P3` | Да | Приоритет |
| `response_min` | Целое, минуты | Да | Норматив реакции |
| `resolve_min` | Целое, минуты | Да | Норматив решения |

Нормативы из примера кейса:

| Приоритет | Реакция, мин | Решение, мин |
|---|---:|---:|
| P1 | 15 | 60 |
| P2 | 30 | 240 |
| P3 | 120 | 480 |

## 3. Справочники контрольного набора

Справочники заполняет Администратор 1С до импорта (UC-04).

| Справочник | Значения |
|---|---|
| Очереди | `L1` — первая линия, `L2` — вторая линия |
| Исполнители | `E01`, `E02`, `E03` (условные коды, без персональных данных) |

## 4. Проверки при импорте

| Код | Проверка | Что отклоняется | Компонент | Проверка приёмки |
|---|---|---|---|---|
| V1 | Структура: есть все обязательные колонки | Файл целиком, до загрузки | К2 | T-01 |
| V2 | Обязательные поля заполнены | Обращение | К2 | T-02 |
| V3 | Ссылки: очередь и исполнитель есть в справочниках, событие ссылается на обращение | Обращение | К3 | T-03 |
| V4 | Хронология: `created_at ≤ first_response ≤ resolved`; `created_at ≤ closed_at` | Обращение | К4 | T-04, T-05 |
| V5 | Уникальность: не больше одного `first_response` и одного `resolved` на обращение | Обращение | К5 | T-06 |
| V6 | Для приоритета есть норматив SLA | Обращение | К6 | T-07 |

**Частичная загрузка (ОВ-6):** обращение с любой ошибкой V2 – V6 отклоняется целиком вместе с событиями, остальные загружаются. Ошибка V1 — файл не загружается. Повтор строки по ключам ADR-0003 — не ошибка, а пропуск дубликата.

## 5. Правила расчёта

| Показатель | Правило |
|---|---|
| Время реакции, мин | `first_response.ts − created_at` |
| Время решения, мин | `resolved.ts − created_at` |
| Нарушение | Факт > норматива; равенство — не нарушение (ОВ-4) |
| Нет события | Время не рассчитывается (не 0). Если к концу периода отчёта срок по нормативу уже истёк — **нарушение**; если ещё не истёк — показатель не определён и в долю нарушений не входит (ОВ-3) |
| Доля нарушений реакции / решения | Нарушения / обращения, где показатель определён (рассчитан или просрочен) × 100 %, отдельно |
| `breach_rate` в экспорте | Обращения, где нарушена реакция или решение / обращения, где есть нарушение или оба показателя определены, × 100 % (решение команды ОВ-5) |
| Период для SLA | Обращения, у которых `created_at` попадает в период |
| Активное обращение | От `assigned` до `resolved`; без `resolved` — до конца периода; активно во все дни, которые пересекает интервал (ОВ-7) |
| Дневная загрузка | Число активных обращений исполнителя за день |
| Средняя загрузка | Среднее по парам «исполнитель — день» с ≥ 1 активным обращением (ОВ-8) |
| Разброс загрузки | Максимальная и минимальная дневная загрузка среди тех же пар (решение команды, В-5) |
| `load_avg` в экспорте | Средняя загрузка по обращениям группы «очередь — приоритет» |
| Округление | Средние — 2 знака, доли — 1 знак, проценты |
| Пустое значение в экспорте | Показатель не определён для группы (например, нет ни одного решённого обращения) |

### 6.5. Изменение норматива

Если норматив реакции P1 изменить с 15 на 20 мин и пересчитать: T002 (20 мин) перестаёт быть нарушением; доля нарушений реакции — 11,1 % (1 / 9), `breach_rate` — 37,5 % (3 / 8).
